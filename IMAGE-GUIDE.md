# Adding portfolio images

1. Put optimized JPG, PNG, or WebP files in `public/images/`.
2. Open `app/content.ts`.
3. Set a project's `image` value, for example: `image: "/images/eyeguide-cover.jpg"`.
4. Change project text, tags, or array order in the same file.

Recommended names:

- `portrait.jpg`
- `eyeguide-cover.jpg`
- `robotics-cover.jpg`
- `green-building-cover.jpg`
- `stem-workshop-cover.jpg`
- `children-workshop-01.jpg`
- `concept-sketch.jpg`
- `prototype.jpg`
- `final-product.jpg`

Recommended sizes:

- Project covers: 1400 × 1000 px
- Portrait: 1000 × 1400 px
- Gallery images: at least 1400 px wide
- Prefer WebP or compressed JPG under 1 MB when practical
